# OmniTube

YouTube TV (Leanback, интерфейс youtube.com/tv) для ПК-консоли, который **корректно работает с оверлеем Steam**.

## Зачем

VacuumTube и другие клиенты на Electron/Chromium рисуют картинку через собственный GPU-процесс и DirectComposition, поэтому оверлей Steam либо не появляется, либо работает криво.

OmniTube устроен как игра. Chromium (CEF) рендерит страницу в текстуру вне экрана, а приложение само выводит её в собственный DirectX 11 swap chain и вызывает `Present` каждый кадр. Steam подключается к этому `Present` штатно, как к любой D3D11-игре. Геймпад читается через XInput прямо в процессе приложения, поэтому, пока открыт оверлей, Steam забирает ввод себе.

## Установка

1. Скачайте `OmniTube-win-x64.zip` из релиза **latest** и распакуйте в любую папку, например `C:\Games\OmniTube`.
2. В Steam добавьте `OmniTube.exe` как стороннюю игру.
3. В свойствах ярлыка, в разделе «Контроллер», включите Steam Input. Тогда любой геймпад, включая DualSense, будет виден приложению как Xbox-контроллер.

## Управление

| Геймпад | Действие |
|---|---|
| D-pad / левый стик | навигация |
| A | выбрать |
| B | назад |
| X, Y, LB, RB, LT, RT | как в приложении YouTube на консоли |
| Guide | меню Steam |

Выход: «Выйти» в самом YouTube (B на главном экране), Alt+F4 или «Выйти из игры» в меню Steam.

## Файлы

Всё лежит в `%APPDATA%\OmniTube\`:

- `config.json` — настройки (создаётся при первом запуске);
- `omnitube.log` — лог приложения, его нужно прислать при проблемах;
- `cef.log` — лог Chromium;
- `cef\` — профиль браузера (вход в аккаунт, кэш).

### config.json

| Ключ | По умолчанию | Описание |
|---|---|---|
| `url` | `https://www.youtube.com/tv` | стартовая страница |
| `sharedTexture` | `true` | передавать кадры через GPU. Если GPU-путь не заработает, приложение само переключится на `false` (через системную память, медленнее) |
| `frameRate` | `60` | частота кадров Chromium |
| `uiHeight` | `1080` | логическая высота интерфейса, который масштабируется на экран |
| `windowed` | `false` | окно 1280×720 вместо полного экрана (для отладки) |
| `language` | `""` | Accept-Language; пусто — язык Windows |
| `hideCursorAfterSeconds` | `3` | через сколько секунд скрывать курсор мыши |
| `extraFlags` | `[]` | дополнительные флаги Chromium, например `["--disable-gpu-sandbox"]` |

## Сборка

GitHub Actions собирает приложение при каждом push в `main` и публикует релиз `latest`.

Локально:

```
dotnet publish OmniTube.csproj -c Release -o publish
```

Нужен .NET 8 SDK. Приложение собирается self-contained, поэтому .NET на целевой машине не требуется.
