# OmniTube

YouTube TV (Leanback, интерфейс youtube.com/tv) для ПК-консоли, который **корректно работает с оверлеем Steam**.

## Зачем

VacuumTube и другие клиенты на Electron/Chromium рисуют картинку через собственный GPU-процесс и DirectComposition, поэтому оверлей Steam либо не появляется, либо работает криво.

OmniTube устроен как игра. Chromium (CEF) рендерит страницу в текстуру вне экрана, а приложение само выводит её в собственный DirectX 11 swap chain и вызывает `Present` каждый кадр. Steam подключается к этому `Present` штатно, как к любой D3D11-игре. Геймпад читается через XInput прямо в процессе приложения, поэтому, пока открыт оверлей, Steam забирает ввод себе.

## Функции VacuumTube

Модули страницы из [VacuumTube](https://github.com/shy1132/VacuumTube) встроены в приложение без изменений:
- блокировка рекламы;
- SponsorBlock;
- DeArrow;
- счётчик дизлайков (Return YouTube Dislike);
- скрытие Shorts;
- отключение запроса «Продолжить просмотр?»;
- h264ify;
- управление скоростью и громкостью;
- прочие мелкие улучшения.

Их настройки находятся внутри YouTube: «Настройки» → «VacuumTube» (на клавиатуре — Ctrl+O). Пункты, которые относятся к окну VacuumTube и его автообновлению, скрыты. Поиск устройств для трансляции (DIAL) не работает, потому что ему нужен прямой сетевой доступ, но привязка телефона по коду с ТВ работает.

Отключить модули целиком можно в `config.json`: `"vacuumTubeModules": false`.

## Установка

1. Скачайте `OmniTube-win-x64.zip` из релиза **latest** и распакуйте в любую папку, например `C:\Games\OmniTube`.
2. В Steam добавьте `OmniTube.exe` как стороннюю игру.
3. В свойствах ярлыка, в разделе «Контроллер», включите Steam Input. Тогда любой геймпад, включая DualSense, будет виден приложению как Xbox-контроллер.

## Заставка

Пока играет видео, OmniTube сообщает Windows, что экран используется: так же поступают браузеры и видеоплееры. Заставка Big Picture (она учитывает такие запросы), заставка Windows и отключение экрана в это время не срабатывают. На паузе и в меню запрос снимается, и заставка работает как обычно. Беззвучные превью в меню не считаются.

Кроме того, пока идёт видео, OmniTube раз в 20 секунд сбрасывает системный таймер бездействия «пустым» движением мыши на 0 пикселей: курсор не двигается и не появляется. Таймер заставки Steam считает именно ввод пользователя, и одного запроса к Windows ему недостаточно.

Проверить можно так: во время воспроизведения команда `powercfg /requests` показывает строку «OmniTube: playing video», а в `omnitube.log` появляются строки `Video playing` и `Idle timer reset while playing`.

## Автообновление

OmniTube обновляется сам:
1. Через минуту после запуска и затем раз в 6 часов он сверяет свою версию с релизом `latest` на GitHub (по коммиту, из которого собран).
2. Если есть новая сборка, она скачивается в фоне. Когда загрузка закончится, в углу экрана появится уведомление.
3. Установка происходит при обычном выходе: «Выйти» в YouTube или Alt+F4. Просмотр ничто не прерывает. Если процесс был убит (например, через «Выйти из игры» в Steam), обновление дождётся следующего нормального выхода.

Предыдущая версия сохраняется в `%APPDATA%\OmniTube\previous`. Откатиться можно так (PowerShell):

```
gps OmniTube -ea 0 | kill -f; Copy-Item "$env:APPDATA\OmniTube\previous\*" C:\Games\OmniTube -Recurse -Force
```

Отключить автообновление можно в `config.json`: `"autoUpdate": false`.

## Управление

| Геймпад | Действие |
|---|---|
| D-pad / левый стик | навигация |
| A | выбрать |
| B | назад |
| X, Y, LB, RB, LT, RT | как в приложении YouTube на консоли |
| Guide | меню Steam |

Выход: «Выйти» в самом YouTube (B на главном экране), Alt+F4 или «Выйти из игры» в меню Steam.

## Файлы

Всё лежит в `%APPDATA%\OmniTube\`:

- `config.json` — настройки (создаётся при первом запуске);
- `omnitube.log` — лог приложения, его нужно прислать при проблемах;
- `cef.log` — лог Chromium;
- `cef\` — профиль браузера (вход в аккаунт, кэш).

### config.json

| Ключ | По умолчанию | Описание |
|---|---|---|
| `url` | `https://www.youtube.com/tv` | стартовая страница |
| `sharedTexture` | `true` | передавать кадры через GPU. Если GPU-путь не заработает, приложение само переключится на `false` (через системную память, медленнее) |
| `frameRate` | `60` | частота кадров Chromium |
| `uiHeight` | `1080` | логическая высота интерфейса, который масштабируется на экран |
| `windowed` | `false` | окно 1280×720 вместо полного экрана (для отладки) |
| `keepAwakeWhilePlaying` | `true` | пока играет видео, не давать включаться заставке Steam/Windows и гаснуть экрану |
| `autoUpdate` | `true` | автообновление из релиза GitHub |
| `updateRepo` | `aafnx/omnitube` | репозиторий с релизом `latest` |
| `vacuumTubeModules` | `true` | подключать модули VacuumTube |
| `language` | `""` | Accept-Language; пусто — язык Windows |
| `hideCursorAfterSeconds` | `3` | через сколько секунд скрывать курсор мыши |
| `extraFlags` | `[]` | дополнительные флаги Chromium, например `["--disable-gpu-sandbox"]` |

## Сборка

GitHub Actions собирает приложение при каждом push в `main` и публикует релиз `latest`.

Локально (нужны .NET 8 SDK и Node.js 20+):

```
git submodule update --init
cd web && npm ci && node build.mjs && cd ..
dotnet publish OmniTube.csproj -c Release -o publish
```

`web/build.mjs` собирает модули VacuumTube из сабмодуля `third_party/VacuumTube` (закреплён на конкретном коммите) в один скрипт, который встраивается в exe. Если после обновления сабмодуля какой-то патч перестанет применяться, сборка остановится с ошибкой.

### Обновление VacuumTube

Workflow `update VacuumTube` запускается каждый понедельник. Если вышел новый релиз VacuumTube, он:
1. переводит сабмодуль на этот релиз;
2. собирает бандл и прогоняет `web/test/smoke.cjs` (модули загружаются без ошибок, геймпад, выход, разрешение);
3. при успехе коммитит в `main` и запускает сборку, после чего релиз `latest` обновляется.

Если что-то не прошло, ничего не выпускается, а в репозитории появляется issue с меткой `vacuumtube-update` и логом. Запустить проверку вручную или выбрать конкретную версию можно на вкладке Actions → update VacuumTube → Run workflow.

Иконка генерируется скриптом `assets/make_icon.py`. Чтобы поставить свою, замените `assets/app.ico`.
